網站建置期 SEO 優化技術指南

Technical SEO & Architecture Checklist ｜ 內部教育訓練講義

1. 伺服器與基礎安全性

  • HTTPS 加密協定：全站強制使用 SSL 憑證，確保資料傳輸安全，符合搜尋引擎排名基本要求。
  • 伺服器回應速度：優化硬體資源與資料庫查詢，縮短 TTFB（首位元組時間），確保基礎連線效率。

2. 檢索與索引控制 (Crawlability)

  • Robots.txt：正確配置以引導爬蟲抓取重要頁面，阻擋無價值參數網址，節省檢索預算。
  • XML Sitemap：建置動態生成的網站地圖，確保文章、產品等核心頁面即時更新並提交。
  • Canonical 標準網址：針對動態參數（如篩選、排序、分頁）設定標準網址標記，避免重複內容分散權重。

3. 網站架構與網址結構

  • 扁平化架構：重要頁面須能從首頁以 3 至 4 次點擊內抵達，確保爬蟲能深入檢索。
  • 語意化網址 (SEF)：採用簡短、包含關鍵字的靜態化網址，並使用連字號 (-) 分隔單字。
  • 內部連結與麵包屑：建立符合搜尋意圖的導覽結構，麵包屑需具備權重傳遞與輔助定位功能。

4. 行動裝置與效能指標 (Core Web Vitals)

  • RWD 響應式設計：全面落實行動裝置優先檢索 (Mobile-First Indexing)，觸控元件間距需符合規範。
  • LCP (最大內容繪製)：首屏最大元素載入時間應低於 2.5 秒。
  • INP (互動延遲)：優化 JavaScript 執行效率，減少主執行緒阻塞。
  • CLS (累計版面位移)：為圖片與多媒體預留長寬比空間，避免畫面非預期跳動。

5. 網頁標籤與結構化資料 (On-Page)

  • Meta 標籤系統：後台必須開放自訂 Title 與 Meta Description 的獨立欄位。
  • H1-H6 階層語意：遵循 HTML 規範，單頁唯一 H1，依照內容邏輯依序使用標題標籤。
  • 圖片 Alt 屬性：圖片管理系統需具備替代文字欄位，提供搜尋引擎辨識圖片內容。
  • Schema.org JSON-LD：將結構化資料（如文章、常見問題、機構資訊等）整合入網頁程式碼，爭取複合式搜尋結果。
